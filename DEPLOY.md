# Deploy FarmLink Online (free)

Two easy options. Option A (Render) gives you a public link like
`https://farmlink.onrender.com` in about 5 minutes.

---

## Option A - Render.com (recommended, free)

### 1. Put the project on GitHub
```bash
git init
git add .
git commit -m "FarmLink"
```
Create a new **public repository** on github.com, then:
```bash
git remote add origin https://github.com/YOUR-USERNAME/farmlink.git
git push -u origin main
```

### 2. Deploy on Render
1. Go to https://dashboard.render.com → **New +** → **Web Service**
2. Connect your GitHub account and pick the `farmlink` repo
3. Render reads `render.yaml` automatically. Confirm:
   - Build command: `pip install -r requirements.txt`
   - Start command: `waitress-serve --host 0.0.0.0 --port $PORT app:app`
4. Under **Environment**, add if you have them:
   - `RAZORPAY_KEY_ID` / `RAZORPAY_KEY_SECRET` (optional, for online payment)
   - `SECRET_KEY` is auto-generated by render.yaml
5. Click **Create Web Service** and wait ~3 minutes

Done — share your URL with anyone.

> Note: the free tier uses an ephemeral disk, so uploaded images / the SQLite DB
> reset on redeploy. For permanent storage either upgrade to a paid instance with
> a persistent disk, or use Option B.

---

## Option B - PythonAnywhere (free, data persists)

1. Sign up at https://www.pythonanywhere.com (free "Beginner" account)
2. Files tab → Upload the whole `farm-market` folder (or clone from GitHub in a Bash console)
3. Consoles → **Bash**:
   ```bash
   pip3.10 install --user flask waitress
   ```
4. Web tab → **Add a new web app** → Manual configuration → Python 3.10
5. In the **WSGI file** replace its content with:
   ```python
   import sys
   path = "/home/YOUR-USERNAME/farm-market"
   if path not in sys.path:
       sys.path.insert(0, path)

   from app import app as application
   ```
6. Reload the web app

Your site: `https://YOUR-USERNAME.pythonanywhere.com`

---

## Before going live (both options)

- [ ] Set a strong `SECRET_KEY` env variable (never commit it)
- [ ] Add Razorpay keys if you want online payments to work
- [ ] Register yourself as admin: run `py make_admin.py your@email.com` locally,
      or in a Render/PythonAnywhere shell
- [ ] Optional demo data: run `py seed.py` once
